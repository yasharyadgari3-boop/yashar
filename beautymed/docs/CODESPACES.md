# دیدن و امتحان کامل سایت در GitHub Codespaces

با Codespaces کل سایت (پایگاه داده، ورود آزمایشی، فروشگاه، پرداخت آزمایشی، پنل‌ها و کتابخانه) در مرورگر شما اجرا می‌شود؛ بدون نصب چیزی روی کامپیوتر و بدون انتخاب هاست. همه‌ی سرویس‌ها آزمایشی‌اند: پیامکی فرستاده نمی‌شود و پولی جابه‌جا نمی‌شود.

## هزینه

- GitHub برای حساب شخصی هر ماه سهمیه‌ی رایگان Codespaces می‌دهد. این تنظیم از ماشین ۲ هسته‌ای استفاده می‌کند، که تقریباً **۶۰ ساعت روشن بودن در ماه** رایگان است.
- اگر ۳۰ دقیقه کاری نکنید، Codespace خودش خاموش می‌شود. کارتان که تمام شد، خودتان هم خاموشش کنید (بخش «خاموش و حذف کردن»).
- اگر روش پرداختی در GitHub ثبت نکرده‌اید، با تمام شدن سهمیه هزینه‌ای گرفته نمی‌شود. برای اطمینان: GitHub ← Settings ← Billing and licensing.

## بار اول (حدود ۵ تا ۱۰ دقیقه)

۱. در مرورگر به صفحه‌ی مخزن بروید: `https://github.com/yasharyadgari3-boop/yashar`

۲. دکمه‌ی سبز **Code** را بزنید، سربرگ **Codespaces** را انتخاب کنید، سپس **Create codespace on main**.

۳. یک صفحه‌ی ویرایشگر (شبیه VS Code) در مرورگر باز می‌شود. پایین صفحه پنجره‌ی ترمینال، نصب را نشان می‌دهد. صبر کنید تا این جمله را ببینید:
`Setup finished. The site starts when the codespace opens (port 3000).`
و بعد:
`Starting BeautyMed on port 3000.`

۴. وقتی سایت آماده شد، معمولاً پیامی با دکمه‌ی **Open in Browser** ظاهر می‌شود. آن را بزنید. اگر پیامی ندیدید: پایین صفحه سربرگ **PORTS** را باز کنید، روی ردیف **BeautyMed (3000)** نشانگر را ببرید و آیکون کره‌ی زمین (Open in Browser) را بزنید.

۵. باز شدن اولین صفحه حدود یک دقیقه طول می‌کشد (سایت در حالت توسعه، هر صفحه را بار اول می‌سازد). صفحه‌های بعدی سریع‌ترند.

## حساب‌های آزمایشی

در صفحه‌ی **ورود پزشکان** یکی از این شماره‌ها را وارد کنید. پیامکی فرستاده نمی‌شود؛ در صفحه‌ی بعد، **کد ۶ رقمی در یک کادر نوشته شده است**. همان را وارد کنید.

| شماره | نقش | چه چیزی را امتحان کنید |
|---|---|---|
| `09120000001` | مدیر | تأیید پزشکان و واردکننده‌ها، دیدن مدارک، انتشار یا رد محصول، سفارش‌ها، دوره‌ها، تنظیمات پابمد، نمایش قیمت برای بازدیدکننده |
| `09120000002` | پزشک تأییدشده | خرید کامل: افزودن به سبد ← تسویه ← درگاه آزمایشی ← سفارش؛ باز کردن درس‌های آموزشی |
| `09120000003` | پزشک در انتظار تأیید | نمی‌تواند سفارش دهد یا درس را باز کند |
| `09120000004` | واردکننده‌ی تأییدشده | ثبت محصول (تا تأیید مدیر منتشر نمی‌شود)، دیدن سفارش‌های محصولات خودش، پیشنهاد همکاری |
| `09120000005` | واردکننده‌ی در انتظار تأیید | دسترسی محدود |
| هر شماره‌ی دیگر | کاربر تازه | ثبت‌نام پزشک یا واردکننده با آپلود مدرک (یک فایل PDF یا تصویر دلخواه) |

برای عوض کردن نقش: از حساب خارج شوید (در پنل) و با شماره‌ی دیگری وارد شوید. برای دیدن سایت مثل یک بازدیدکننده، خارج شوید.

## دفعه‌های بعد

به `https://github.com/codespaces` بروید و روی Codespace خود بزنید. نصب تکرار نمی‌شود؛ سایت خودش روشن می‌شود و از مرحله‌ی ۴ بالا ادامه دهید. داده‌هایی که ساخته‌اید (سفارش‌ها، محصولات) می‌مانند.

## خاموش و حذف کردن

- **خاموش کردن** (داده‌ها می‌مانند): در `https://github.com/codespaces`، کنار Codespace روی «…» بزنید و **Stop codespace**.
- **حذف** (وقتی دیگر لازم نیست؛ فضای ذخیره را هم آزاد می‌کند): همان‌جا **Delete**. هر وقت خواستید، از مرحله‌ی ۲ یک Codespace تازه بسازید.

## اگر مشکلی پیش آمد

- **صفحه خطای ۵۰۲ نشان می‌دهد:** سایت هنوز در حال روشن شدن است؛ یک دقیقه صبر کنید و صفحه را دوباره بارگذاری کنید.
- **ترمینال بسته شد یا سایت باز نمی‌شود:** در ترمینال (منوی ☰ ← Terminal ← New Terminal) این را بنویسید و Enter بزنید:

```bash
bash beautymed/scripts/codespace.sh start
```

باید `Starting BeautyMed on port 3000.` را ببینید، یا اگر سایت روشن است `The site is already running on port 3000`.

- **دکمه‌ی Codespaces برای حساب شما فعال نیست:** به من بگویید تا راه دیگری (اجرا روی کامپیوتر خودتان) را آماده کنم.

## نکته‌ها

- این فقط برای بررسی است، نه سایت واقعی. نشانی Codespace خصوصی است و فقط با حساب GitHub خودتان باز می‌شود.
- تنظیمات آن در پوشه‌ی `.devcontainer/` در ریشه‌ی مخزن است (تنها استثنای قاعده‌ی «همه‌چیز داخل beautymed/»، چون GitHub فقط آنجا را می‌خواند) و اسکریپت `beautymed/scripts/codespace.sh`. هیچ‌کدام روی هاست اصلی استفاده نمی‌شود.
