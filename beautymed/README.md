## اجرای محلی (روی کامپیوتر خودتان)

پیش‌نیاز: Node.js نسخه‌ی ۲۲ و PostgreSQL نسخه‌ی ۱۶.

۱. نصب بسته‌ها:

```bash
npm install
```

۲. ساخت فایل تنظیمات: از `.env.example` یک کپی با نام `.env` بسازید و `DATABASE_URL` و `AUTH_SECRET` را پر کنید (توضیح هر مورد داخل همان فایل است).

۳. ساخت جدول‌های پایگاه داده:

```bash
npm run db:deploy
```

۴. افزودن کاربران و محصولات آزمایشی (اختیاری، فقط برای آزمایش):

```bash
npm run db:seed
```

۵. اجرای سایت:

```bash
npm run dev
```

سپس `http://localhost:3000` را در مرورگر باز کنید.

## تست‌ها

```bash
npm run typecheck
npm run lint
npm test
npm run e2e
```

`npm test` به پایگاه `beautymed_test` و `npm run e2e` به پایگاه `beautymed_e2e` نیاز دارد (نشانی‌ها در `tests/test-env.ts`). تست مرورگر، پایگاه `beautymed_e2e` را هر بار خالی و دوباره پر می‌کند و به هیچ پایگاه دیگری دست نمی‌زند.
